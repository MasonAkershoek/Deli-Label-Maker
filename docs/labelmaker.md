# Label Maker
---
> ## Intro

The label maker portion of the deli label maker allows you to make, edit, save and create labels for reuse. In this section we will describe how to use the label maker and all of its features.

The way this page is laid out is that each of the titled boxes containing input fields will have each of its fields described with what it dose.

> #### Who made it and Dish Title

**Chef** - This box is for the name of the person who made the dish and is required.

**Dish Name** - This box is for the name of the dish made.

**Department** - This box is for organization purposes and is auto populated with Kitchen however Bakery and Misc are also options and is required.

> ### Food Allergens

This box contains three common food allergens that will be automatically inserted into the dish description when the label is made.

> ### Weight and Price

**Price** - This box is for entering the price of the dish. DO NOT enter a "$" sign as it will be automatically inserted into the label when it is created.

**Weight** - This box is for the weight. It is not necessary to enter the weight type as that is selected below.

**Weight Type** - In this drop down menu you may select from three weight types or NONE which will display no weight or weight type on the label when created.

> ### Template and Date

**Template** - In this dropdown box you will select which label template to use of the label.

**Exp Date** - This box allows you to choose a expiration date for the dish.

**No Date** - Checking this box tells the label maker not to display an expiration date on the label, used if you will date the product yourself.

> ### Dish Description

This large text box is where you will enter ingredients and any other relevant information about the dish you are making the label for. It is not necessary to enter any of the three food allergens above or to add the text Ingredients: to the description as they will be inserted automatically into the label upon creation.

> ### Actions

**Create Label** - This button will create a label which will automatically be opened in Adobe Acrobat for inspection and to be printed, it will also automatically save the label date to the label manager for future use.

**Save Label** - This button will save the label to the label manager without creating it.

**Clear** - This button will clear all felids of the label maker.
