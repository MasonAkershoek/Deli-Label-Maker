# Label Manager

---

> ## Intro

This section describes the label manager portion of the program. This part of the program is used to manage the save labels that have been made. This helps reduce desktop clutter and makes it easy to access frequently used labels for reuse.

> ## Label Manager Screen (Departments)

<img

The three sections at the top labeled ["Kitchen", "Bakery", "Misc"] will display labels that where added to that specific department when created making it easier to find labels by what department they where in.

The search section allows you to search labels with text. You will enter your search into the box at the top then with the drop down box you can search only showing results from a specific department. Results will populate in the box on the left.

> ### Actions Box

**Edit** - This button will bring you to the label maker window with all the fields populated with the data of the selected label. This can be used to edit parts of the label for printing such as changing the expiration date or if ingredients have changed ect.

**Create** - This button will create the label and open it up in Adobe Acrobat. Used when you know you want to make the label without having to edit it.

**Delete** - This button will delete the label from the label manager.

**Favorite/ Unfavorite** - This button will favorite or unfavorite a label. When favorited it will show up in the favorites section of the label manager.
